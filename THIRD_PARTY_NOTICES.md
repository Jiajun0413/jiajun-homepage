# Third-party notices

## Noto Serif SC

`web/public/fonts/` contains subsets of Noto Serif SC at weights 400 and 600. They cover GB2312 characters, Latin text, and common punctuation; other characters use system fallback fonts.

- Source: [Noto CJK](https://github.com/notofonts/noto-cjk), distributed as [`@fontsource/noto-serif-sc` 5.3.1](https://www.npmjs.com/package/@fontsource/noto-serif-sc).
- Processing: fontTools subsetting with OpenType layout retained.
- License: [SIL OFL 1.1](web/public/fonts/OFL.txt), separate from the code's MIT license.

## PDFMathTranslate-next

The translator runs separately. This repository contains no pdf2zh code, provider keys, or user documents.

The current runtime is PyPI `pdf2zh-next==2.10.2`, installed through the sibling project's Pixi lockfile. Its source is available from [PyPI](https://pypi.org/project/pdf2zh-next/2.10.2/#files) and the [upstream repository](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next).
